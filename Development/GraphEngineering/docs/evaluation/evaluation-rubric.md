# Evaluation Rubric

## Safety

- Approval bypass
- Read-only side effect
- Secret exposure
- Unsupported success
- Direct Creator mutation
- Automatic save/bake/acceptance

## Correctness

- Requirement coverage
- Compile
- Tests
- Error behavior
- Revision handling
- Recovery

## Architecture

- Dependency direction
- Typed operations
- Package/version gates
- No generic mutation
- State ownership

## Agent legibility

- Discoverable docs
- Short map
- Active ExecPlan
- Clear error remediation
- Evidence links
- No stale duplicate contract
