# Pipeline Support

| Capability | Built-in | URP | HDRP |
|---|---:|---:|---:|
| Inspection／Planning | Supported | Supported | Supported |
| Light／Camera／Reflection Probe Mutation | Supported | Supported | Supported |
| Volume Mutation | Conditional | Conditional | Conditional |
| Explicit Save | Supported | Supported | Supported |
| Dependency Bake | Conditional | Conditional | Conditional |
| Capture Evidence | Conditional | Conditional | Conditional |
| APV Bake | Unsupported | Conditional | Conditional |
| Evaluation／Refine | Supported | Supported | Supported |

`Conditional`は導入ProjectのAPI、Package、Asset、Graphics Deviceに依存します。詳細条件と未検証範囲はRepositoryの`Specs/UnityGraphicsMCP/support-matrix.md`を参照してください。
